Sistem Persamaan Linear Dua Variabel (SPLDV)

Tentang Kolaborasi Ini

Apa itu SPLDV?

Sistem Persamaan Linear Dua Variabel (SPLDV) merupakan sistem persamaan yang disusun oleh dua persamaan linear dengan dua variabel (misalnya x dan y) dan setiap variabelnya berpangkat satu. Catatan: variabel yang digunakan tidak hanya x dan y, tetapi dapat menggunakan pasangan huruf lain, misalnya p dan q, atau huruf lainnya.

  • 🧮 Menghitung jumlah bahan yang diperlukan
  • 💰 Mengoptimalkan biaya produksi untuk setiap produk
  • 📊 Menganalisis efisiensi penggunaan limbah dalam berbagai varian lampu
  • ⚖️ Menyeimbangkan proporsi bahan untuk hasil optimal

Poster SPLDV Kami

SPLDV: Divania Estika Etiningtiyas

Metode Campuran SPLDV

Variabel

x = Harga satu lampu hias

y = Harga satu kipas angin smart

Persamaan

3x + 4y = Rp 435.000

4x + 5y = Rp 555.000

Metode Campuran

1. Eliminasi

3x + 4y = Rp 435.000 | × 5

4x + 5y = Rp 555.000 | × 4

15x + 20y = Rp 2.175.000

16x + 20y = Rp 2.220.000

_______________________ _

-1 = -45.000/p>

x = Rp -45.000 : -1

x = Rp.45.000

2. Substitusi

3x + 4y = 435.000

3(45.000) + 4y = 435.000

135.000 + 4y = 435.000

4y = 435.000 - 135.000

4y = Rp 300.000

y = 300.000 : 4

y = Rp 75.000

Kesimpulan

Jadi, harga satu lampu hias adalah Rp 45.000 dan harga satu kipas angin smart adalah Rp75.000.

SPLDV: Lucky Cahaya Putra

Metode Campuran SPLDV

Variabel

x = Harga satu Pot keyboard bekas

y = Harga satu Keylight

Persamaan

3x + 2y 155.000 (1)

2x + 5y 250.000 (2)

Metode Campuran

1. Eliminasi

3x + 2y = 155.000 | × 2

2x + 5y = 250.000 | × 3

6x + 4y = 310.000

6x + 15y = 750.000

_______________________ _

-11y = -440.000

11y = 440.000

y = 440.000 : 11

y = 40.000

2. Substitusi

3x + 2(40.000) = 155.000

3x + 80.000 = 155.000

3x = 75.000

x = 75.000 : 3

x = 25.000

Kesimpulan

Jadi, harga satu pot dari keyboard bekas adalah Rp25.000 dan harga satu keylight adalah Rp40.000.

SPLDV: Lutfiana Safitri Wulandari

Metode Campuran SPLDV

Variabel

x = Harga satu Keylight

y = Harga satu Pot Keyboard

Persamaan

2x + 5y = 205.000

5x + 2y = 250.000

Metode Campuran

1. Eliminasi

2x + 5y = 205.000 | × 2

5x + 2y = 250.000 | × 5

4x + 10y = 410.000

25x + 10y = 1.250.00

_______________________ _

-21x = -840.000

x = 840.000 : 21

x = 40.000

2. Substitusi

2x + 5y = 205.000

2(40.000) + 5y = 205.000

80.000 + 5y = 205.000

5y = 205.000 - 80.000

5y = 125.000

y = 125.000 : 5

y = 25.000

Kesimpulan

Jadi, harga satu Keylight adalah Rp40.000 dan harga satu Pot Keyboard adalah Rp25.000.

Pembelajaran yang Didapat

1

Aplikasi Matematika dalam Kehidupan Nyata

SPLDV dapat digunakan untuk menyelesaikan masalah sehari-hari, seperti menghitung harga barang, menentukan jumlah barang, dan menghitung total pembelian.

2

Pemecahan Masalah Sistematis

Saya belajar menyelesaikan masalah secara bertahap, mulai dari memahami soal, menentukan variabel, membuat persamaan, hingga menemukan jawaban yang tepat.

3

Integrasi Lintas Disiplin

Saya belajar bahwa matematika dapat dihubungkan dengan pelajaran lain, seperti ekonomi dan kewirausahaan, terutama dalam menghitung harga, keuntungan, dan jumlah barang.
